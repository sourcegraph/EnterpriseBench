## What F2 flags

`benchmark_qa_core.check_aux_file_leakage` raises **F2** when an oracle file
path (from `[ground_truth].required_files` / `sufficient_files` in
`task.toml`) appears verbatim, as a whole word, inside an agent-visible aux
file — here `instruction.md`. The EB adapter already downgrades F2 from
`error` to `warning` because several task families legitimately name the file
under investigation. This triage resolves the **specific-path** camp left open
by the 2026-04-30 run.

## Count reconciliation

* **12 tasks**, **14 F2 warnings**.
  * `api-contract-002` → `balancer/balancer.go` **and** `resolver/resolver.go`
  * `config-drift-004` → `manifests/ha/base/redis-ha/chart/values.yaml`
    **and** `charts/redis-ha/values.yaml`

All 14 are triaged below.

## Decision rule

A path in `instruction.md` is a **leak** only if it reveals a *discriminative*
answer the task scores the agent for *discovering*. Across all 12 tasks the
named path is instead the **given investigation entry point** — the changed
file, the migration artifact, the config under audit, or (nats) the repo
directory name — while the scored discovery (downstream consumers, the
specific drift value, the bypass scenario, the impact surface) is **never
named**. Every verdict is therefore **waive** (false positive for the task
family), not redact and not accept-as-leak.

No task names a to-be-discovered consumer/impact file, so **no redactions**
are warranted: redacting an entry point would make these impact-analysis
tickets unrealistic or unsolvable (you must tell the agent which upstream
change to assess).

## How the decisions are recorded

Each task's `task.toml` gains a `[[qa.waivers]]` entry (one per token):

```toml
[[qa.waivers]]
code = "F2"
token = "metadata/metadata.go"
decision = "waive"
rationale = "..."
approved_by = "stephanie.jarmak (dec-uon CLOSED)"
bead = "EnterpriseBench-1is"
date = "2026-06-04"
```

The adapter (`lib/eb_verify/qa_adapter.py`) reads these waivers and downgrades
a matched F2 from `warning` to `info`, appending the rationale to the message.
The finding stays visible as an audit trail (not swallowed) but no longer
counts as a warning or fails strict mode. Token matching is exact (by `repr`),
so a waiver for one path cannot suppress a different path's F2.

Schema: `schemas/task.schema.json` now documents the optional top-level `qa`
table and its `waivers` array.

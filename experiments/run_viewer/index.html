EnterpriseBench run browser

Every scored run under results/runs/: 1,046 runs across 186 tasks and 10 tool-access modes. A row is one agent session in one container. Click it for per-checkpoint scores, the MCP tool breakdown, and how the session opened. Modes differ only in filesystem permissions on the repo checkouts; the toolset handed to the agent is identical across all of them.

Two columns are worth reading before you compare anything. Context tok is what the model actually read, summed from the run trace as uncached input plus cache creation plus cache reads; a Claude harness reports total_input_tokens with cache reads excluded, which understates it by two or three orders of magnitude. Where a trace was captured only in part the reported figure is the larger of the two and is used instead; the detail panel names the source on every row. Score is on a 0–1 scale: runs written before the scorer moved to a weighted mean carry a weighted sum, and those are divided by total checkpoint weight, with the raw value kept in the detail panel.
